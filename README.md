# c64mine
A minesweeper game for the Commodore 64.
## Build
### Tools you need:
- make
- 64tass
```
git clone https://github.com/morvo1/c64mine
cd c64mine
make
```
## Run
To run the game, I recommend using the VICE emulator. If you have it installed, just type the command below into your terminal after making sure you are in the repo's folder.
```
make run
```
